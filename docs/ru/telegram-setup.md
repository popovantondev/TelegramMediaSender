# Подключение Telegram

Программа использует MTProto API Telegram через Telethon. Создайте собственные API-данные для своего аккаунта. Токен бота не нужен.

## Получите API ID и API Hash

1. Откройте [my.telegram.org](https://my.telegram.org) и войдите по номеру Telegram.
2. Откройте **API development tools** и создайте приложение.
3. Скопируйте числовой **api_id** и **api_hash**. Официальное описание: [получение API ID](https://core.telegram.org/api/obtaining_api_id).
4. В Telegram Media Sender нажмите «Профили…» → «Добавить…», задайте имя профиля и укажите номер телефона, API ID и API Hash.

Храните API Hash в секрете. Программа сохраняет его локально вместе с профилем. Не отправляйте его в чаты, задачи или снимки экрана.

## Войдите в аккаунт

1. Выберите профиль и нажмите «Обновить», чтобы загрузить чаты.
2. Введите код входа, который Telegram отправит на уже авторизованное устройство или другим доступным для аккаунта способом.
3. Если включена двухэтапная проверка, введите пароль по запросу.
4. Выберите чат и убедитесь, что это правильный получатель, прежде чем отправлять файлы.

В документации Telethon описан вход по коду и паролю [двухэтапной проверки](https://docs.telethon.dev/en/stable/basic/signing-in.html). После входа программа хранит сессию локально, поэтому повторно вводить код при каждом запуске не требуется. Файл сессии содержит данные авторизации и должен храниться в секрете — см. [документацию о сессиях](https://docs.telethon.dev/en/stable/concepts/sessions.html).

## Как отозвать доступ

В Telegram откройте «Настройки → Устройства» (название может отличаться на разных платформах) и завершите сессию этой программы. Если профиль больше не нужен, удалите его через «Профили…» → «Удалить…». Это удаляет данные и сессию только новой программы; профили старой программы, сообщения Telegram и исходные медиафайлы сохраняются. Удаление локальной сессии не отзывает её копии.
