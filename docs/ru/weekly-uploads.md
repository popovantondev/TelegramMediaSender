# Учёба по неделям

## Подготовьте папки

Выберите корневую папку, внутри которой лежат папки `Неделя <номер> …`. Номер недели определяет порядок. Внутри недели создайте папки дней с действительными датами `YYYY-MM-DD`.

```text
Учеба телеграм/
├── Неделя 1 03.08 - 08.08/
│   ├── Неделя_01_Материалы_на_неделю.zip
│   ├── 2026-08-03/
│   │   ├── 01_Аудио/Лекция 01.mp4
│   │   ├── 02_Субтитры/Лекция 01.de.srt
│   │   └── 04_Дополнительные_материалы.zip
│   └── 2026-08-04/
└── Неделя 2 10.08 - 14.08/
```

Файлы непосредственно в папке недели отправляются как общие материалы недели. В день можно добавлять вложенные папки. Программа упорядочивает недели по номеру, дни по дате и файлы по естественному порядку названия. Для дня порядок такой: аудио и видео, все `.srt`, `03_Скриншоты.zip`, `04_Дополнительные_материалы.zip`, затем прочие файлы. Каждый файл отправляется отдельно. Аудио и поддерживаемое видео сохраняют встроенное воспроизведение Telegram.

Пустые категории допустимы. Системные файлы macOS исключаются. Символические ссылки и папки с неверной датой показываются в проблемах и не добавляются в очередь.

## Выбор и отправка

Первое сканирование выбирает все найденные недели, дни и материалы недели. Снимите галочки с ненужных частей; частично выбранная неделя показывает промежуточную галочку. При обновлении существующий выбор сохраняется, а новые папки отмечаются автоматически.

Нажмите **Проверить и отправить…**, проверьте профиль, чат, объём и вложенный план сообщений, затем отдельно нажмите **Начать отправку**. Заголовок недели или дня отправляется только тогда, когда для него выбраны файлы.

### Импорт готового плана публикации

Нажмите **Импортировать план публикации…** и выберите JSON-файл формата `publication-plan-v1`. Приложение проверит структуру, порядок элементов, идентификаторы, размер и SHA-256 файлов относительно папки плана. Затем покажет отдельный предварительный просмотр. Подтверждение предварительного просмотра только загружает план в таблицу; отправка начинается лишь после обычной проверки очереди и отдельного нажатия **Начать отправку**. Перед отправкой файлы проверяются повторно. Если план или файл изменился, импорт/отправка останавливается — пересканируйте или импортируйте актуальную редакцию. Импортированный план сохраняет порядок, текст, ID проекта и редакции; повторная отправка привязана к профилю и чату.

Перед отправкой программа постранично проверяет историю выбранного чата. Совпадение учитывает точный текст либо имя и размер файла; это только подсказка, содержимое файла таким способом не подтверждается. Для каждого возможного совпадения нужно выбрать действие. Одно сообщение Telegram нельзя использовать для нескольких элементов. Проверка отменяется остановкой очереди; до её завершения отправка не начинается.

Во время активной очереди macOS временно блокирует автоматический сон компьютера. Экран может выключаться, а после завершения, остановки или ошибки блокировка снимается. Группы Telegram с темами пока не поддерживаются: приложение показывает их количество и не отправляет в тему по умолчанию.

До отправки приложение получает текущий лимит загрузки подключённого аккаунта Telegram. Для одного файла действует меньшая из двух границ: лимит аккаунта и лимит программы — 2 000 000 000 байт. Превышающий её файл блокирует очередь до начала отправки.

## Продолжение и остановка

Журнал хранится в локальной папке данных приложения. Для продолжения выберите сохранённую очередь и тот же профиль и чат. Отправленные элементы останутся в журнале. Незавершённая отправка сначала сверяется с чатом. Программа не начинает отправку автоматически при запуске.

При остановке выберите **Дождаться текущего файла** или **Прервать передачу сейчас**. Если Telegram уже мог принять сообщение, результат помечается неопределённым и проверяется перед продолжением. Изменение исходного файла требует обновить план; старый отпечаток не отправляется.

## Диагностика и приватность

Локальный журнал можно открыть в окне «Профили» кнопкой **Открыть журнал диагностики…**. На Mac он находится в `~/Library/Application Support/TelegramMediaSender/diagnostics.jsonl`; сохраняется текущий файл и не более двух ротированных копий. Перед передачей журнала в поддержку откройте его и проверьте содержимое. Приложение не отправляет журнал автоматически.

Журнал содержит версию приложения, тип события и безопасные счётчики. В него не записываются тексты исключений, коды Telegram, API Hash, сессии, текст сообщений, имена чатов, профилей и файлов или пользовательские пути.

## Изолированный тестовый запуск

Для тестовой копии передайте приложению `--data-dir PATH`. Профили, сессии, журнал и настройки будут созданы в указанной папке, без переноса старых профилей. Например, запустите исполняемый файл приложения с `--data-dir /tmp/telegram-media-sender-preview-data`.
