Telegram Media Sender

Sendet nummerierte Pakete aus Video, Audio und Untertiteln in der gewählten Reihenfolge an Telegram.

Release · 1.1.2
Herunterladen für macOSAnleitung ↗

Vor dem StartEigenes Telegram-Konto, API ID und API Hash erforderlich; keine Apple-Notarisierung.

So funktioniert es

  1. Dateien wählen
  2. Reihenfolge festlegen
  3. An Telegram senden

Erste Schritte
