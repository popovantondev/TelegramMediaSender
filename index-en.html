Installation

The steps from “First launch” in the guide.

1. Download the ZIP from GitHub Releases and unzip it
2. Move the app to the Applications folder
If Gatekeeper blocks it: System Settings → Privacy & Security → Open Anyway
3. Add a profile with your phone number, API ID and API Hash
4. Enter the login code, and your two-step verification password if asked
5. Load chats, choose the target chat, select bundles, send

Sends to Telegram

The app runs locally on your Mac but sends the selected files to Telegram through your own Telegram account. Profiles and session files stay on this Mac; the app contains no keys.

Your own Telegram accountAPI ID + API Hash
