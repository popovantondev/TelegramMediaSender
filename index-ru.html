Telegram Media Sender

Отправляет пронумерованные наборы видео, аудио и субтитров в Telegram в выбранном порядке.

Выпуск · 1.1.2 macOS 13+ · Apple Silicon
Скачать для macOS Исходный код Python · PySide6 Руководство ↗

Перед запускомНужны собственный аккаунт Telegram, API ID и API Hash; приложение не нотарифицировано Apple.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Первый запуск» руководства.

1. Скачать ZIP из GitHub Releases и распаковать
2. Перенести приложение в папку «Программы»
Если Gatekeeper блокирует запуск: Системные настройки → Конфиденциальность и безопасность → Открыть всё равно
3. Добавить профиль с номером телефона, API ID и API Hash
4. Ввести код входа и при запросе пароль двухэтапной проверки
5. Загрузить чаты, выбрать целевой чат, отметить наборы, отправить

Отправляет в Telegram

Приложение работает локально на вашем Mac, но отправляет выбранные файлы в Telegram через ваш собственный аккаунт. Профили и файлы сессий остаются на этом Mac; ключей в приложении нет.

Свой аккаунт TelegramAPI ID + API Hash

Проверено

  • Автоматические проверки в GitHub Actions (macOS 15): компиляция, модульные тесты, сборка приложения
  • Контрольная сумма SHA-256 (SHA256SUMS.txt) в релизе
  • Версия 1.1.2 и журнал изменений
  • Запуск скачанного релиза проверен и описан (docs/release-check.md); другой Mac ещё не проверялся
  • Руководство на немецком, английском и русском

Как это работает

  1. Выбрать файлы
  2. Задать порядок
  3. Отправить в Telegram
