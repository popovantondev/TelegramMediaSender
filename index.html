Telegram Media Sender

Sendet nummerierte Pakete aus Video, Audio und Untertiteln in der gewählten Reihenfolge an Telegram.

Release · 1.1.2 macOS 13+ · Apple Silicon
Herunterladen für macOS Quellcode Python · PySide6 Anleitung ↗

Vor dem StartEigenes Telegram-Konto, API ID und API Hash erforderlich; keine Apple-Notarisierung.

Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „Erster Start“ in der Anleitung.

1. ZIP aus GitHub Releases laden und entpacken
2. App in den Ordner „Programme“ verschieben
Blockiert Gatekeeper: Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen
3. Profil mit Telefonnummer, API ID und API Hash anlegen
4. Anmeldecode eingeben, bei Bedarf das Passwort der Zwei-Schritt-Verifizierung
5. Chats laden, Zielchat wählen, Pakete markieren, senden

Sendet an Telegram

Die App läuft lokal auf Ihrem Mac, sendet die gewählten Dateien aber über Ihr eigenes Telegram-Konto an Telegram. Profile und Sitzungsdateien bleiben auf diesem Mac; die App enthält keine Schlüssel.

Eigenes Telegram-KontoAPI ID + API Hash
